# ASSL 后续量化研究方向

更新日期：2026-08-22

## 当前共识

ASSL 不把上市公司简单划成“好公司”和“坏公司”。市场信息天然不完整，A 股在不少阶段也会由流动性、情绪、政策和主题交易主导，因此基本面只能作为带有不确定性的证据，不能冒充客观真相。

更合适的研究框架是把信息拆成几个互补层次：

1. 市场环境决定当前信号的总体可信度，重点观察宽度、成交活跃度、波动率、行业扩散程度和指数趋势。
2. 行业及个股相对强度回答资金正在选择什么。
3. MACD、均线和量价结构用于识别入场时机。
4. 基本面及主观研究标签用于调整研究优先级、提示风险和解释信号，不默认作为一票否决条件。

## 基本面信息的使用原则

- 不使用“好/坏公司”二元标签，改用“已有研究基础”“证据增强”“证据减弱”“信息不足”等状态。
- 允许“未知”，不为了量化而制造虚假的精确评分。
- 区分经营事实、市场预期和主观判断，并保留来源及更新时间。
- 基本面层首先用于排序和风险提示；只有财务异常、重大负面事件等可验证事项才考虑硬性排除。
- 当前自选股已有的主观研究结论可以先作为人工标签；完整的历史财务因子回测必须使用公告日可得数据，防止未来数据泄漏。

## 候选研究通道

### 1. 市场环境与参与度

候选指标包括：自选池及全市场站上 MA20/MA60 的比例、上涨家数比例、成交额变化、量能扩散、行业集中度、指数波动率和跌停数量。该层主要承担阈值调整、风险降级或暂停某类信号的职责。

`market-regime-v1.1` 已进入独立影子运行：使用沪深300趋势（30分）、自选池宽度（30分）、参与活跃度（25分）和下跌压力（15分）形成0—100分市场温度。参与活跃度进一步拆成上涨家数比例（7.5分）、自选池活跃量能宽度（7.5分）和两市总成交额（10分）；总成交额比较5日/20日均值并结合120日分位，若放量同时出现指数显著下跌和大跌家数扩散，则成交额加分封顶为4分，避免把恐慌抛售当作健康活跃。70分及以上为风险偏好，45—69.9分为中性震荡，45分以下为风险规避。风险规避期暂停预测金叉晋级，只保留强S/S的确认金叉或底背离修复信号。行业扩散因尚无稳定行业分类数据，暂不计分。

### 2. 行业与个股相对强度

比较行业相对宽基指数、个股相对行业的 20/60 日强度，并研究 52 周新高接近度、残差强度和量价确认。该层用于解决多个 MACD 信号同时出现时的排序问题。

### 3. 基本面变化与技术共振

研究营收、扣非利润、ROE、现金流和盈利质量的变化，而不是只看静态高低。重点验证“基本面证据增强后出现 MACD/均线确认”是否优于单独技术信号。

### 4. 上升趋势中的回撤修复

作为追随趋势信号的互补通道，仅研究中期趋势未破坏、短期缩量回撤并重新确认的候选，避免把下降趋势中的超跌反弹混入。

## 实现复杂度与顺序

- 市场环境、成交活跃度和相对强度主要依赖现有 OHLCV，复杂度较低，可优先实验。
- 主观基本面标签叠加复杂度较低，但要明确其时间戳和“未知”状态。
- 使用历史财务数据进行无未来函数回测复杂度较高，难点是公告日、历史修订、停牌和样本存续偏差，而不是计算公式。
- 各通道保持独立记录，先比较 T+1、T+5、T+10、T+20 收益、相对收益、最大回撤、胜率和覆盖率；只有样本外仍有增量价值的通道才进入正式 Top 10 排序。

## 当前决策

现有生产算法继续保持 MACD 三通道不变。市场环境第一版仅生成原始与调整后候选的对照及独立效果统计；在没有足够前瞻样本前，不写入线上选股权重。

网站新增“策略实验室”作为独立展示入口。自选股版本更新后，所有已启用策略在下一次筛选中使用新版本；实验策略仍保持影子运行，不自动混入生产 Top 10。历史补算默认使用补算时的最新自选股池，必须标记为“历史重构”，并与真实逐日积累的前瞻样本分开统计。
